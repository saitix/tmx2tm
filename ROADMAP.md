# Roadmap

Planned work that is not yet scheduled. Items move into a `REVISION_PLAN.md`
(or direct commits) when approved for implementation.

## Features to be implemented

1. Track 3rd-party apps by version / release tag / checksum.
   In case the tracked value differs from the one saved on install,
   then mark the app as having an update available.

## Possible changes

1. Break the main shell file `tmx2tm.sh` into multiple shell files.
2. Have an assembly tool that makes a single file for release.
